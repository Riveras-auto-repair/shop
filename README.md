# Rivera's Auto Repair

Website for Rivera's Auto Repair, 4304 Lilburn Industrial Way SW, Lilburn, GA 30047.

The whole site is one file, `index.html`. It is in English and Spanish, and it is hosted for free with GitHub Pages at https://riveras-auto-repair.github.io/shop/.

The quote form opens the customer's text or email app with the request already written, addressed to the shop.
